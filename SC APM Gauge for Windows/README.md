## 🎯 컨셉

> 래더 대신 결재를 돌고, 빌드 오더 대신 엑셀 수식을 짜는 당신에게.

한때 300 APM을 찍던 손이 요즘은 메일 답장과 보고서 작성에 쓰이고 있다면, 그 손놀림도 기록할 가치가 있습니다.

**출근 APM**은 업무 중 키보드와 마우스 입력을 세어 **화면 구석의 작은 테란 콘솔**에 실시간 APM으로 띄워 줍니다. 단축키를 연타하며 피벗 테이블을 정리할 때, 마감 직전 메일 다섯 통을 몰아 칠 때, 숫자가 노랗게 달아오르는 걸 보면 오늘 하루가 조금 덜 지루해집니다.

### 이런 분께

- 회의록을 쓰다가 무심코 손가락으로 부대 지정 단축키를 누르는 분
- "요즘 내 손 많이 죽었다"는 걸 숫자로 확인하고 싶은 분
- 금요일 오후 4시에 마지막 불꽃을 태우고 싶은 분
- 옆자리 동료와 오늘 PEAK 기록으로 소소하게 내기하고 싶은 분

### 일부러 하지 않은 것

| 하지 않은 것 | 이유 |
|---|---|
| 큰 창, 화려한 애니메이션 | 업무 화면을 가리면 안 되니까 |
| 효과음 | 사무실은 조용해야 하니까 |
| 입력 기록 저장, 순위표, 서버 전송 | 회사 PC에서 마음 편히 쓰려면 키 입력·클릭 같은 사용 기록은 남기지 않는 게 맞으니까 |
| 실제 게임 로고·이미지 | 분위기만 빌리고 원작 자산은 쓰지 않음 |

## 👀 화면 읽는 법

```text
┌─ ● ─────────────────────────────── ● ─┐
│ ┌──────────────────────────────────┐ │
│ │ ◆ APM               PEAK  312  ■ │ │  ← 오늘 최고 기록 · 입력 LED
│ │                                  │ │
│ │ 손이 안 보임                287  │ │  ← 등급 · 현재 APM
│ │                                  │ │
│ │ ▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▭▭▭▭▭▭     │ │  ← 페이스 게이지
│ └──────────────────────────────────┘ │
└─ ● ─────────────────────────────── ● ─┘
```

| 요소 | 의미 |
|---|---|
| **현재 APM** | 지금 페이스로 1분 동안 계속하면 몇 번 입력하는지 |
| **PEAK** | 실행 후 최고 기록. 30 이상의 기록을 넘어서면 **노랗게 반짝** |
| **입력 LED** | 키를 누르거나 클릭할 때마다 깜빡이는 작은 불빛 |
| **등급** | 지금 페이스에 붙는 한마디 |
| **게이지** | 유닛 체력바처럼 24칸. 400 APM에서 가득 참 |

## 🏅 등급

| APM | 등급 | 이럴 때 |
|---|---|---|
| 0 | **대기** | 커피 타러 감, 혹은 회의 중 |
| 1 ~ 59 | **워밍업** | 출근 직후, 메일함 훑어보는 중 |
| 60 ~ 149 | **업무 중** | 평범하게 일하는 중 |
| 150 ~ 249 | **집중 모드** | 마감이 다가옴 |
| 250 ~ 349 | **손이 안 보임** | 단축키 연타, 엑셀 정리 폭주 |
| 350 이상 | **프로게이머** | 그 시절의 손이 돌아왔다 |

> [!TIP]
> 등급 문구는 `APM.cs`의 `RankFor`에서 마음대로 바꿀 수 있습니다. 팀 분위기에 맞는 문구로 바꿔 보세요.

## 🎨 테마와 초상화

<img src="docs/themes.png" alt="테마 4종과 초상화 애니메이션" width="760">

설정 창에서 테마를 고르면 테두리 재질, 화면 색, 숫자 색, 모서리 장식, 초상화가 한꺼번에 바뀝니다.

| 테마 | 분위기 | 테두리 · 장식 | 초상화 애니메이션 |
|---|---|---|---|
| **클래식** (기본) | 녹색 형광 콘솔 | 브러시드 금속 · 리벳 | 회전하는 **레이더 스캔**과 깜빡이는 점 |
| **테란** | 산업용 강철 | 강철판 · 경고 줄무늬 | 통신 화면 속 **헬멧 실루엣**, 바이저 반사광, 가끔 지직거리는 잡음 |
| **저그** | 생체 조직 | 핏줄 무늬 · 빛나는 돌기 | 맥동하며 두리번거리다 **깜빡이는 생체 눈**, 흔들리는 촉수 |
| **프로토스** | 황금과 사이오닉 에너지 | 황금 판 · 푸른 보석 | 천천히 회전하는 **에너지 결정**, 퍼지는 에너지 고리 |

### 초상화

콘솔 왼쪽에 초상화 칸이 붙습니다. 설정 창의 **초상화** 항목에서 고릅니다.

| 선택 | 동작 |
|---|---|
| 끄기 | 초상화 칸 없이 원래 크기 |
| 테마 애니메이션 | 테마에 맞는 애니메이션 (초당 10장) |
| 사용자 이미지 / GIF | **이미지 선택…** 으로 고른 PNG · JPG · BMP · GIF를 표시. **움직이는 GIF는 그대로 재생**됩니다 |

- 사용자 이미지는 칸을 꽉 채우도록 가운데를 잘라서 보여 주고, 테마의 주사선과 테두리를 덧씌워 콘솔과 어울리게 합니다.
- 이미지는 복사하지 않고 고른 경로에서 읽습니다. 파일을 옮기면 다시 선택해 주세요.
- 직접 넣는 이미지는 저작권 문제가 없는 것을 사용해 주세요.

> [!NOTE]
> 테마와 초상화는 각 종족의 **분위기만 참고해 새로 만든 디자인**입니다. 원작 게임의 초상화·유닛·로고는 그리지 않았습니다.

### 상황 메시지

등급 문구 자리에 짧은 알림이 몇 초 동안 떴다가 사라집니다. 콘솔 크기는 바뀌지 않습니다.

| 언제 | 메시지 |
|---|---|
| 100 이상의 기록을 넘어서는 순간 | 최고 기록 갱신! |
| 250 이상을 10초 유지 | 컨트롤 폭발 중 |
| 오늘 누적 1,000 / 5,000 / 10,000 / 20,000 … 회 | 명령 10,000회 달성 |
| 5분 넘게 입력 없음 | 놀고 있는 일꾼 감지 |
| 10분 넘게 비웠다가 돌아옴 | 사령관 복귀 |
| 점심 10분 전 · 정각 | 보급 10분 전 · 점심 / 보급 시간 · 점심! |
| 퇴근 10분 전 · 정각 | 철수 10분 전 / GG · 퇴근하세요 |
| 설정한 시간(기본 50분) 동안 쉬지 않고 작업 | 50분째 교전 중 · 휴식! |

### 근무 정보 줄

게이지 아래에 한 줄이 추가됩니다.

- **왼쪽:** `퇴근까지 01:12:45`. 퇴근 시간이 지나면 `야근 +00:23:05`
- **오른쪽:** `명령 8,412`. 오늘 누른 횟수이며, 자정에 0으로 돌아갑니다.

### APM 그래프

최근 60초의 APM 흐름을 리플레이 그래프처럼 보여 줍니다. 오른쪽 위 숫자는 그래프의 최대 눈금입니다.

## 🔧 설정

콘솔을 **우클릭 → 설정…** 하면 설정 창이 열립니다. 바꾸는 즉시 콘솔에 반영되므로 미리 보면서 고를 수 있습니다.

| 구분 | 항목 | 기본값 |
|---|---|---|
| 디자인 | 테마 | 클래식 |
| 디자인 | 초상화 · 사용자 이미지 | 테마 애니메이션 · 없음 |
| 표시 | 등급 문구 · 입력 LED · 상황 메시지 · 근무 정보 줄 | 켜짐 |
| 표시 | APM 그래프 (최근 60초) | 꺼짐 |
| 알림 | 휴식 알림 · 연속 작업 시간 | 켜짐 · 50분 |
| 알림 | 점심 시간 | 12:00 |
| 알림 | 퇴근 시간 | 18:00 |
| 계기판 | 투명도 | 94% |
| 계기판 | 게이지 최대 APM | 400 |
| 계기판 | APM 평균 시간 | 5초 |
| 저장 | 종료할 때 설정 자동 저장 | 켜짐 |

### 저장과 불러오기

| 버튼 | 동작 |
|---|---|
| **설정 저장** | `APM.exe`와 같은 폴더의 `APM.ini`에 저장합니다. 파일이 없으면 새로 만들고, 있으면 덮어씁니다. 지금 콘솔 위치도 함께 저장됩니다. |
| **종료할 때 자동 저장** | 켜 두면 콘솔을 끌 때 위와 같은 방식으로 자동 저장합니다. 위치를 옮기거나 설정을 바꾼 뒤 저장 버튼을 깜빡해도 다음 실행 때 그대로 뜹니다. |
| **설정 불러오기…** | 다른 폴더에 있는 설정 파일도 골라서 바로 적용할 수 있습니다. 다음 실행 때도 쓰려면 이어서 **설정 저장**을 누르세요. |
| **기본값** | 모든 설정을 처음 상태로 되돌립니다. |

실행할 때 `APM.exe`와 같은 폴더에 `APM.ini`가 있으면 **자동으로 읽어 적용**합니다.

<details>
<summary><b>APM.ini 예시 (메모장으로 직접 고쳐도 됩니다)</b></summary>
<br>

```ini
; 출근 APM 설정 파일
; 메모장으로 직접 고쳐도 됩니다. 1 = 켜기, 0 = 끄기
; 화면 설정만 들어 있습니다. 키 입력·클릭 같은 사용 기록은 저장하지 않습니다.

[디자인]
Theme=classic       ; classic(클래식) · terran(테란) · zerg(저그) · protoss(프로토스)
Portrait=1          ; 초상화 0 = 끄기, 1 = 테마 애니메이션, 2 = 사용자 이미지
; 사용자 초상화 이미지 경로 (PNG·JPG·BMP·GIF). 이 줄에는 주석을 붙이지 마세요.
PortraitImage=D:\images\my-portrait.gif

[표시]
Rank=1              ; 등급 문구
Led=1               ; 입력 LED
Messages=1          ; 상황 메시지
Info=1              ; 근무 정보 줄 (퇴근 카운트다운 · 총 명령)
Graph=0             ; APM 그래프 (최근 60초)

[알림]
BreakReminder=1     ; 연속 작업 시 휴식 알림
BreakMinutes=50     ; 휴식 알림까지 연속 작업 시간 10~180 (분)
LunchTime=12:00     ; 점심 시각 (HH:mm)
OffTime=18:00       ; 퇴근 시각 (HH:mm)

[계기판]
Opacity=94          ; 투명도 30~100 (%)
MaxGauge=400        ; 게이지가 가득 차는 APM
WindowSec=5         ; APM 평균 시간 1~30 (초)

[저장]
AutoSave=1          ; 종료할 때 자동 저장

[위치]
PosX=1660
PosY=24
```

모르는 항목이나 잘못된 값은 건너뛰고 기본값을 씁니다.

</details>

> [!TIP]
> 팀원들과 같은 설정을 쓰고 싶다면 `APM.ini` 하나를 공유 폴더에 두고 각자 **설정 불러오기 → 설정 저장**을 하면 됩니다.

## 📦 설치

설치할 것이 없습니다. Windows에 기본으로 들어 있는 .NET Framework 4.x 컴파일러로 `.exe` 하나를 만듭니다.

| 항목 | 내용 |
|---|---|
| OS | Windows 10 / 11 |
| 런타임 | .NET Framework 4.x (기본 포함) |
| 추가 설치 | **없음** |

```text
office-apm/
├── APM.cs        ← 소스 코드
├── build.bat     ← 빌드 스크립트
├── APM.ini       ← 설정 파일 (저장하면 생김, 없어도 됨)
└── docs/
    ├── preview.png
    ├── features.png
    └── themes.png
```

1. 저장소를 내려받습니다.
2. **`build.bat`** 을 더블클릭합니다.
3. 만들어진 **`APM.exe`** 를 실행하면 화면 오른쪽 위에 콘솔이 나타납니다.

### 조작

| 동작 | 기능 |
|---|---|
| <kbd>좌클릭</kbd> + 드래그 | 콘솔 이동 |
| <kbd>우클릭</kbd> | 메뉴: **설정…** / **종료** |
| <kbd>더블클릭</kbd> | 종료 |

## 📐 APM은 어떻게 계산되나

자동차 **속도계**와 같습니다. 시속 100km가 "1시간 동안 100km를 갔다"는 뜻이 아니라 "지금 속도로 1시간 달리면 100km"라는 뜻이듯, 출근 APM도 **지금 페이스로 1분 동안 계속하면 몇 번인가**를 보여 줍니다.

| 상황 | 동작 |
|---|---|
| ⚡ **막 치기 시작할 때** | 치기 시작한 순간부터의 페이스로 바로 반응. 1초에 5번 누르면 곧바로 **300** |
| 🎯 **계속 칠 때** | 최근 5초 평균 페이스. 300 페이스면 정확히 300 |
| ⬇️ **손을 뗐을 때** | 최근 5초에서 입력이 하나씩 빠져나가며 **부드럽게** 내려감 |

| 경과 | 0초 | 1초 | 2초 | 3초 | 4초 | 5초 |
|---|:-:|:-:|:-:|:-:|:-:|:-:|
| 300 페이스로 치다 멈춤 | 300 | 약 240 | 약 180 | 약 120 | 약 60 | 0 |
| 1초에 5번 치고 멈춤 | 300 | 200 | 150 | 100 | 75 | 50 → 0 |

<details>
<summary><b>무엇을 1회로 세나</b></summary>
<br>

| 입력 | 집계 |
|---|---|
| 키보드 키 누름 | ✅ 1회 (꾹 누를 때의 자동 반복은 제외) |
| 마우스 좌클릭 · 우클릭 | ✅ 1회 |
| 마우스 이동 · 휠 · 키를 뗄 때 | ❌ |

</details>

<details>
<summary><b>수식과 조정 값</b></summary>
<br>

```text
측정 시간   = clamp(지금 − 치기 시작한 시각, 1초, 5초)
현재 페이스 = 최근 5초의 입력 횟수 ÷ 측정 시간 × 60
화면 숫자   = 현재 페이스를 0.25초 시상수로 따라감 (한 번에 최소 1씩)
```

| 상수 | 기본값 | 의미 |
|---|---|---|
| APM 평균 시간 | `5초` | 설정 창에서 변경. `3`이면 빨리 떨어지고 `10`이면 묵직함 |
| 게이지 최대 APM | `400` | 설정 창에서 변경 |
| `MinSpanSec` | `1.0` | 막 치기 시작했을 때의 최소 측정 시간 (코드에서 변경) |
| `FollowTau` | `0.25` | 화면 숫자가 따라가는 속도 (코드에서 변경) |

</details>

## 💼 회사에서 써도 되나

키보드 입력을 감지하는 프로그램이라 이 부분은 분명히 해 둡니다.

> [!IMPORTANT]
> **키 입력·클릭 같은 사용 기록은 어디에도 저장하지 않습니다.** 파일로 남는 것은 화면 설정(`APM.ini`)뿐이며, **설정 저장**을 누르거나 자동 저장이 켜진 상태에서 종료할 때만 기록됩니다.

| 항목 | 내용 |
|---|---|
| 어떤 키를 눌렀는지 | ❌ **저장하지 않음.** 메모리에도 남기지 않음 |
| 언제 눌렀는지 | ❌ APM 계산용으로 최근 5초의 입력 **시각**만 메모리에 두고, 5초가 지나면 바로 버림 |
| 오늘 누른 횟수 | 숫자 하나만 메모리에 둠. 파일에 저장하지 않고, 끄거나 자정이 되면 사라짐 |
| 설정 파일 (`APM.ini`) | 테마·표시 설정·알림 시간·투명도·창 위치·초상화 이미지 경로만 기록. **설정 저장**을 누르거나 자동 저장이 켜진 상태에서 종료할 때만 씀 |
| 초상화 이미지 | 사용자가 고른 이미지를 읽기만 함. 복사하거나 바꾸지 않음 |
| 레지스트리 | ❌ 읽지도 쓰지도 않음 |
| 네트워크 | ❌ 통신 코드 없음 |
| 성능 | 50ms 간격으로 확인하고, 화면이 바뀔 때만 다시 그림 |

<details>
<summary><b>키 코드는 왜 읽나요?</b></summary>
<br>

키를 꾹 누르고 있으면 Windows가 같은 입력을 반복해서 보냅니다. 이것을 1회로만 세기 위해 "이 키가 이미 눌려 있는지"만 확인하고 바로 버립니다.

</details>

> [!WARNING]
> 키보드 감지 구조상 일부 백신이 의심 행위로 오진할 수 있습니다. 회사 PC라면 소스 코드(`APM.cs`) 한 파일을 보안 담당자에게 함께 전달해 검토를 요청하는 것이 가장 확실합니다. 회사 보안 정책이 허용하는 범위에서 사용하세요.

> [!NOTE]
> 관리자 권한으로 실행된 창에 입력할 때는 Windows 보안 정책 때문에 집계되지 않습니다. 그런 창까지 세려면 `APM.exe`를 관리자 권한으로 실행하세요.

## 🙋 자주 묻는 질문

<details>
<summary><b>실제 게임 APM과 숫자가 같나요?</b></summary>
<br>

계산 원리(최근 몇 초의 평균 페이스를 분당으로 환산)는 같지만, 게임은 유닛 명령만 세고 출근 APM은 모든 키 입력과 클릭을 셉니다. 그래서 타자를 많이 치는 날엔 게임보다 높게 나올 수 있습니다. 기분이 좋아지는 쪽이니 괜찮습니다.

</details>

<details>
<summary><b>내 입력 기록이 저장되나요?</b></summary>
<br>

사용 기록은 저장되지 않습니다. PEAK와 오늘 누른 횟수는 실행 중에만 기억하고, 끄면 사라집니다. 파일로 남는 것은 **설정 저장**을 눌렀을 때의 화면 설정(`APM.ini`)뿐입니다.

</details>

<details>
<summary><b>너무 눈에 띄지 않나요?</b></summary>
<br>

232×96 크기의 작은 위젯이고, 소리가 없으며, 작업 표시줄과 <kbd>Alt</kbd>+<kbd>Tab</kbd> 목록에도 나타나지 않습니다. 더 은은하게 쓰고 싶으면 설정 창에서 **투명도**를 낮추거나, 근무 정보 줄·상황 메시지를 끄세요.

</details>

## 🧪 이전 버전

이 저장소는 단순한 녹색 숫자만 띄우던 **프로토타입 APM 계기판**을 발전시킨 버전입니다. 프로토타입이 "측정이 되는가"를 확인했다면, 출근 APM은 "근무 중에 재미가 있는가"에 집중했습니다.

| | 프로토타입 | 출근 APM |
|---|---|---|
| 화면 | 검은 바탕 + 녹색 숫자 | 테마 4종 · 초상화 애니메이션 · 사용자 이미지/GIF · 체력바 게이지 |
| 계산 | 감쇠형 카운터 | 속도계 방식 (최근 5초 페이스) |
| 재미 요소 | - | 등급 문구 · 입력 LED · PEAK 반짝임 · 상황 메시지 · 퇴근 카운트다운 · APM 그래프 |
| 설정 | 코드 수정 후 다시 빌드 | 설정 창 · `APM.ini` 저장 / 불러오기 · 종료 시 자동 저장 |
