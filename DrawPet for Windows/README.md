## ✨ 소개

그리기 창에서 캐릭터 이름을 짓고 64×64 픽셀 그림을 여러 장 그리면, 그 장면들이 애니메이션이 되어 **작업 표시줄 위를 걸어 다닙니다.**

    <td align="center" width="33%">🎞️<br><b>프레임 애니메이션</b><br><sub>최대 32장<br>어니언 스킨 · 실시간 미리보기</sub></td>

- 별도 런타임이나 라이브러리 **설치 없이** Windows 기본 컴파일러로 `.exe` 하나를 만듭니다.
- 캐릭터는 투명 배경으로 **항상 다른 창 위에** 표시되고, 투명한 부분은 클릭이 아래 창으로 통과합니다.
- 여러 캐릭터를 동시에 띄울 수 있습니다.

## 🚀 빠른 시작

### 요구 사항

| 항목 | 내용 |
|---|---|
| OS | Windows 10 / 11 |
| 런타임 | .NET Framework 4.x (Windows에 기본 포함) |
| 추가 설치 | **없음** (Visual Studio 불필요) |

### 빌드 및 실행

```text
DrawPet/
├── DrawPet.cs       ← 소스 코드
└── build_pet.bat    ← 빌드 스크립트
```

1. 저장소를 내려받거나 두 파일을 같은 폴더에 둡니다.
2. **`build_pet.bat`** 을 더블클릭합니다.
3. `[OK] DrawPet.exe built.` 메시지가 나오면 **`DrawPet.exe`** 를 실행합니다.

> [!NOTE]
> 빌드 스크립트는 `%WINDIR%\Microsoft.NET\Framework64\v4.0.30319\csc.exe`(없으면 32비트 경로)를 사용합니다.

> [!TIP]
> 캐릭터는 **오른쪽을 보도록** 그리세요. 왼쪽으로 걸을 때는 자동으로 좌우가 뒤집힙니다.

## 🖌️ 그리기 창

<!-- <p align="center"><img src="docs/editor.png" alt="그리기 창" width="720"></p> -->

### 그리기 도구

| 도구 | 좌클릭 | 우클릭 |
|---|---|---|
| **펜** | 현재 색으로 그리기 | 지우기 |
| **지우개** | 지우기 | 지우기 |
| **채우기** | 같은 색 영역을 현재 색으로 채우기 | 같은 색 영역을 투명하게 |

- **굵기:** 1~8 픽셀 (기본 2)
- **색:** 16색 팔레트, `다른 색...`으로 원하는 색 선택
- **실행 취소:** <kbd>Ctrl</kbd> + <kbd>Z</kbd> 또는 `실행 취소` 버튼
- **이 프레임 지우기:** 현재 프레임을 비움 (실행 취소 가능)

### 프레임 (애니메이션)

| 버튼 | 기능 |
|---|---|
| `+ 새 프레임` | 현재 프레임 뒤에 빈 프레임 추가 |
| `복제` | 현재 프레임을 복사해 뒤에 추가 (조금씩 고쳐 그리기 좋음) |
| `삭제` | 현재 프레임 삭제 (마지막 한 장이면 내용만 지움) |
| `◀ 앞으로` / `뒤로 ▶` | 프레임 순서 변경 |

아래쪽 썸네일 목록을 클릭하면 그 프레임으로 이동합니다. 프레임은 최대 **32장**까지 만들 수 있습니다.

### 보기 / 움직임 설정

| 설정 | 기본값 | 설명 |
|---|---|---|
| 이름 | (비어 있음) | 캐릭터 머리 위에 표시될 이름. **내보내기 전 필수** |
| 애니 속도(FPS) | `6` | 1초에 넘어가는 프레임 수 (1~30) |
| 이동 속도 | `3` | 걷는 속도 (0~10). `0`이면 제자리에서 애니메이션만 재생 |
| 크기 | `2배` | 바탕화면 캐릭터 크기 (1~4배) |
| 어니언 스킨 | 켜짐 | 바로 앞 프레임을 흐리게 비춰 동작을 이어 그리기 쉽게 함 |
| 격자 | 켜짐 | 픽셀 격자 표시 (8칸마다 진한 선) |
| 왼쪽으로 갈 때 좌우 반전 | 켜짐 | 왼쪽으로 걸을 때 그림을 자동으로 뒤집음 |

### 화면에 내보내기

`▶ 화면에 내보내기`를 누르면 캐릭터가 화면 위에서 떨어지며 나타납니다.

- 누를 때마다 한 마리씩 추가됩니다.
- 내보낸 뒤 그림을 고쳐도 이미 나간 캐릭터는 바뀌지 않습니다. 고친 그림으로 다시 내보내세요.
- 비어 있는 프레임은 자동으로 건너뜁니다.

## 🚶 바탕화면 캐릭터

캐릭터는 작업 표시줄 위를 걷다가 가끔 **멈춰 쉬거나 뒤돌고**, 화면 끝에 닿으면 방향을 바꿉니다. 쉬는 동안에는 첫 번째 프레임으로 서 있습니다.

### 조작

| 동작 | 기능 |
|---|---|
| <kbd>좌클릭</kbd> + 드래그 | 캐릭터를 들어서 옮김 (놓으면 바닥으로 떨어짐) |
| <kbd>더블클릭</kbd> | 그 캐릭터 닫기 |
| <kbd>우클릭</kbd> | 메뉴 열기 |

**우클릭 메뉴**

- `그리기 창 열기`
- `방향 바꾸기`
- `이 캐릭터 닫기`
- `모두 종료`

### 종료하기

<details>
<summary><b>종료 방법 자세히 보기</b></summary>
<br>

| 상황 | 방법 |
|---|---|
| 캐릭터 하나만 닫기 | 캐릭터 **더블클릭** |
| 전부 끄기 | 캐릭터 **우클릭 → 모두 종료** |
| 캐릭터가 돌아다니는 중에 그리기 창을 닫음 | 창만 **숨겨집니다.** 캐릭터 우클릭 → `그리기 창 열기`로 다시 열 수 있습니다. |
| 캐릭터 없이 그리기 창을 닫음 | 프로그램이 종료됩니다. |
| 응답이 없을 때 | 작업 관리자(<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Esc</kbd>)에서 `DrawPet.exe` **작업 끝내기** |

그리기 창과 모든 캐릭터가 닫히면 프로그램이 완전히 종료됩니다.

</details>

## 💾 저장 형식

`저장`을 누르면 모든 프레임을 **가로로 이어 붙인 PNG 한 장**으로 저장합니다.

```text
┌──────┬──────┬──────┬──────┐
│  1   │  2   │  3   │  4   │   ← 64×64 프레임 4장
└──────┴──────┴──────┴──────┘
          256 × 64 PNG
```

- 파일 이름이 캐릭터 이름이 됩니다. (예: `고양이.png` → 이름 "고양이")
- `불러오기`로 다시 열어 이어 그릴 수 있습니다.

<details>
<summary><b>다른 프로그램에서 그린 그림 불러오기</b></summary>
<br>

PNG, BMP, GIF, JPG를 불러올 수 있습니다.

- 그림의 **높이를 한 칸 크기**로 보고, 가로로 잘라 프레임을 만듭니다.
- 각 칸은 64×64로 맞춰집니다. (픽셀이 번지지 않게 확대/축소)
- 반투명 픽셀은 투명 또는 불투명으로 정리됩니다. (캐릭터 테두리가 지저분해지지 않게)
- 세로가 더 긴 그림은 위쪽 정사각형 부분만 한 장으로 불러옵니다.

</details>

> [!NOTE]
> 애니 속도, 이동 속도, 크기 설정은 PNG에 저장되지 않습니다. 불러온 뒤 다시 정해 주세요.

## 🔒 보안 및 개인정보

- 네트워크 통신과 레지스트리 접근 코드가 **없습니다.**
- 파일은 사용자가 `저장` / `불러오기`에서 **직접 고른 그림 파일만** 읽고 씁니다.
- 키보드·마우스를 전역으로 감지하지 않습니다. 그리기 창과 캐릭터 창 위에서의 마우스 동작만 처리합니다.
- 소스 코드(`DrawPet.cs`) 한 파일로 전체 동작을 확인할 수 있습니다.

## 🛠️ 문제 해결

| 증상 | 해결 |
|---|---|
| `csc.exe not found` | "Windows 기능 켜기/끄기"에서 **.NET Framework 4.x**를 켜세요. |
| 빌드 시 파일을 쓸 수 없음 | 이전에 만든 `DrawPet.exe`가 실행 중입니다. 종료 후 다시 빌드하세요. |
| 화면의 한글이 깨짐 | `DrawPet.cs`가 **UTF-8 (BOM 포함)** 으로 저장되어 있는지 확인하세요. |
| 캐릭터에 구멍이 뚫려 보임 | 투명 처리용 색(자홍색 `#FF00FF`)은 자동으로 비슷한 색으로 바뀝니다. 다른 프로그램에서 만든 그림이라면 다시 불러와 보세요. |
| 캐릭터가 화면에서 사라짐 | 모니터 구성이 바뀌었을 수 있습니다. 작업 관리자에서 종료 후 다시 실행하세요. |
| 백신이 실행을 차단 | 소스 코드를 함께 전달해 예외 등록을 요청하세요. |

## 📁 프로젝트 구조

```text
DrawPet/
├── DrawPet.cs        # 전체 소스 (그리기 창 + 바탕화면 캐릭터)
├── build_pet.bat     # 빌드 스크립트 (Windows 내장 csc.exe 사용)
└── README.md
```

<details>
<summary><b>코드 구성</b></summary>
<br>

| 클래스 | 역할 |
|---|---|
| `Program` | 시작·종료 관리 (그리기 창과 캐릭터가 모두 닫히면 종료) |
| `Px` | 픽셀 그림 도우미 (프레임 생성, 채우기, 확대 그리기) |
| `DrawCanvas` | 64×64 그림판 |
| `ThumbBox` | 프레임 썸네일 |
| `PreviewBox` | 애니메이션 미리보기 |
| `EditorForm` | 그리기 창 (도구, 프레임 관리, 저장/불러오기) |
| `PetForm` | 바탕화면 캐릭터 창 (걷기·쉬기·떨어지기, 마우스 조작) |

</details>
